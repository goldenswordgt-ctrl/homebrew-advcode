# homebrew-advcode

Homebrew tap for [advcode](https://github.com/goldenswordgt-ctrl/advcode) — the AI coding agent that learns from experience.

## Install

```sh
brew tap goldenswordgt-ctrl/advcode
brew install advcode
```

Upgrade:

```sh
brew upgrade advcode
```

## Formula checksums

The `Formula/advcode.rb` SHA256 is updated on each release. See the [publish workflow](./.github/workflows/release.yml) for how releases are built.

## Requirements

- macOS (Apple Silicon / arm64 currently supported)
- Homebrew
